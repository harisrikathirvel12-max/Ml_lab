Review Helpfulness Prediction

Project algorithm: TF-IDF text features + Logistic Regression.
Output: Helpful (1) or Not Helpful (0).

Requirements:
  pandas
  scikit-learn

Install dependencies:
  python -m pip install pandas scikit-learn

Run:
  python review_helpfulness_prediction.py

Note: This is a small demonstration dataset. Its accuracy is not representative of a real-world model. Use a larger labeled review dataset for a full project.
